# Lector óptico

App para corregir ensayos SIMCE y PAES con una foto de la hoja de respuestas.

**Abrir e instalar:** entra al link de GitHub Pages de este repositorio desde el celular.
- Android (Chrome): menú ⋮ → *Instalar app* o *Agregar a pantalla principal*.
- iPhone (Safari): botón Compartir → *Agregar a inicio*.

Después de abrirla una vez funciona sin internet.

**Dónde quedan los datos:** solo en el celular (o computador) donde la usas. Nada se sube a este repositorio.
Usa *Ajustes → Descargar respaldo* de vez en cuando, y *Restaurar respaldo* para pasar los datos a otro equipo.

Este repositorio se genera con `construir.py` (carpeta `web/`). Para actualizar la app, se reemplazan estos archivos.
